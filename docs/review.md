# 3.0.0-beta.2 发布与验证

维护者已确认 beta.2 发布，发布前单 EXE 的 UI 修复及弹窗优化已获用户实机验收。本次 GitHub API / 远端引用查询仍仅显示 beta.1，因此发布状态依据维护者确认，不另行声称已核验 beta.2 的线上资产或发布 CI。

## 当前结果

- Inbound 恢复 Fluent 官方指示条与内容切换动画；忙碌时保持选中语义并阻止重复操作，重复点击当前标签保留草稿。
- 统一 11 类弹窗的间距、按钮顺序与安全关闭入口，修复窄窗口换行、低高度编辑器滚动及 UWP 保存/授权等待期间的关闭反馈；镜像 URL 编辑器改为紧凑布局。
- 具体交互、样式和官方依据维护于 [前端规范](frontend.md)，后端权限与更新契约见 [后端规范](backend.md)。无新增生产依赖。

## 验证结论

| 检查 | 结果 |
| --- | --- |
| 前端构建、Node 逻辑检查 | 通过；保留既有大于 500kB bundle 提示 |
| Edge 生产 bundle + 官方 MockIPC | 340 项通过，0 失败；含中间帧、键盘、草稿、防重入及关闭保护 |
| 11 类弹窗视觉矩阵 | 99 组通过：浅/深色 × 320/400/480 宽度，另含低高度、高对比度/减弱动效、200% CSS zoom；已检查截图和动效帧 |
| Windows x64 单 EXE | 构建通过，版本 3.0.0-beta.2、PE Machine 0x8664；用户实机验收通过 |

本地测试证据及构建产物不入库，不作为正式发布资产。本次文档更新不修改代码，不重复执行产品测试。

## 验证边界

UI 改动期间未重跑 Rust 测试、Clippy 或 NSIS 构建；线上发布 CI 与资产未在本次查询中独立核验。用户总体实机确认不等于原生 DPI、文字缩放及完整发布矩阵逐项执行；浏览器 CSS zoom / MockIPC 不能替代这些结论。

此前启动白屏、自动连接检查 UI 及更新功能已获用户确认，旧 alpha 检查更新报错已关闭。管理员代理下载、断网交接安装、慢下载退出、错误签名、安装/升级/卸载与数据保留、托盘/自启、跨账户拒绝和 WebView2 缺失等专项，继续按 [验证与发布指南](development.md) 执行，不将未执行项标为通过。
