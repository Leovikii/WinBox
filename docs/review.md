# 3.0.0 发布准备与验证

维护者已确认 `3.0.0-rc.1` 单 EXE 测试通过，版本清单统一为 `3.0.0`。本次只提交并推送 dev，维护者手动 PR 到 main，由现有工作流构建签名安装包并发布；尚未声称正式版已上线。

## 已完成

- **内部监控统一为 sing-box 原生 API**：最低核心版本1.14，启动和候选核心检查拒绝旧版/未知版本并给出升级提示。通过 gRPC-Web GetVersion 确认就绪、SubscribeStatus 每秒读取网速，保留监听 PID/存活复核、认证、取消和停止清理。
- **兼容两类配置**：优先复用已有可用非TLS原生listener；Clash-only、没有可复用接口或只有TLS接口时，仅向生成配置补随机端口/secret的loopback原生服务。保留原Clash面板与原生TLS服务，保存的订阅不变，不再补Clash监控接口。
- **Web UI 按实际运行配置打开**：原生Dashboard优先，直接打开HTTP(S)根地址由核心跳转；Clash面板打开`/ui/`，避免带secret的根地址401。支持自定义端口、IPv6、通配转loopback、Dashboard三种配置形式。面板未启用/地址不可用给出错误；未生效的编辑不会改变正在运行的面板目标；secret不进入浏览器URL。
- **网速异常恢复**：5秒连接/样本等待界限，数据异常、静默或结束后清零，等待1秒重连；不可用/负数样本归零。停止取消旧任务，前端继续依据后端status清空历史，不从流量推断运行态。
- **默认入站与校验**：TUN补auto_redirect=false；mixed改127.0.0.1:7893，set_system_proxy=true保持不变。其余字段与用户模板一致，三模式/IPv6语义保留。已有自定义覆盖不迁移，Reset采用新默认。保存入站必须是对象且type匹配编辑页，错误保留草稿。
- **实现与文档**：新增prost 0.14.4负责protobuf，网络复用reqwest/Tokio，移除tokio-tungstenite及不再需要的依赖；锁文件和来源/许可证见架构文档。前端IPC参数、流量DTO和Fluent界面结构不变，复用现有错误反馈。同步后端契约、用户指南、验证命令与过时注释。

没有把参考模板的DNS、VLAN、bridge、路由、节点或面板下载策略写入应用默认配置。

## 清理与交付

旧 Clash 网速/就绪实现及其测试已由原生协议回归替代，tokio-tungstenite 及孤立传递依赖已移除；删除原生客户端未使用的 Clone 派生并收紧内部辅助函数可见性。未为清理删除仍有用途的回归、图标源文件或 README 图片。

维护者总体实机验收通过不代表下列专项矩阵逐项执行。

- 本轮真实核心验证使用本地1.14.3，仅loopback面板与临时mixed代理流量，不访问外网，不修改系统代理，不启动TUN。默认字段check不能代替TUN/系统代理/UAC实机验收。
- HTTPS面板地址与TLS服务保留已做代码回归；真实证书、浏览器信任/mTLS未做实机矩阵。内部监控为独立本地接口，不绕过用户TLS策略。
- UI为Edge生产bundle +官方MockIPC；不能代替原生WebView2/Mica、DPI、托盘、自启、UWP和安装/更新实机结果。UWP专项本轮未重跑。
- 本轮未构建NSIS或发布包，未执行安装/升级/卸载和真实更新交接矩阵。正式发布继续按[开发指南](development.md)执行。
- 用户已有自定义mixed监听不自动改写；采用新默认后局域网其他设备不再连接该mixed端口。需要新默认时在Inbound编辑器Reset后Save并重启。
